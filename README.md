# DTC Growth Plugin

Six marketing skills for DTC operators. Built for the Claude Operating System workshop.

## What's inside

- **`/brand-dna-builder`** — Analyzes a website and produces a brand DNA file: positioning, visual identity, tone, differentiators
- **`/brand-voice-profiler`** — Reads 3-5 content samples and codifies the brand's voice into a reusable profile
- **`/icp-deep-dive`** — Builds a tiered ICP matrix with firmographic, psychographic, and behavioral scoring
- **`/hook-writer-meta`** — Writes ad hooks and short-form video scripts for Meta and TikTok
- **`/ad-script-writer`** — Full UGC and direct-response video script system
- **`/creative-brief-generator`** — Turns a product or campaign idea into a designer-ready creative brief

## Install

In Claude Cowork (Desktop):

1. Settings → Customize → click "+" → Add Marketplace
2. Paste this URL:

```
https://github.com/jdcondie/dtc-growth-plugin
```

3. Sync → Install
4. Open a Cowork chat. Type `/` to see the slash commands.

## Recommended order

The skills compound. Run them in this order for the first project:

1. `/brand-dna-builder` — produces `brand/brand-dna.md`
2. `/brand-voice-profiler` — reads the DNA file + your samples, produces `brand/brand-voice.md`
3. `/icp-deep-dive` — produces `brand/icp.md`
4. Then any of the production skills (`/hook-writer-meta`, `/ad-script-writer`, `/creative-brief-generator`) — they all read from the foundation files

Once those three foundation files exist, every downstream skill gets sharper for free.
